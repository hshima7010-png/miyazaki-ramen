⚙️ セットアップが必要です

このマップを動かすには、あなた自身の Google Maps API キー が必要です。

  1. Google Cloud Console でプロジェクトを作成
  2. 「Maps JavaScript API」と「Places API」を有効化
  3. APIキーを発行
  4. このファイルの先頭にある YOUR_API_KEY_HERE を、そのキーに書き換える

※ キーは課金設定が必要ですが、Googleの無料枠内で個人運用は十分まかなえます。キーには「HTTPリファラー制限」をかけて、あなたのサイトURL以外から使われないようにしてください。
